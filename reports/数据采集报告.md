## 二、各数据源采集明细

### 数据源 1：蓝皮书 2026 版（核心数据源）

- **来源 URL**：`http://www.zoucheng.gov.cn/attach/0/92a9af17e661419a938e12d2121c932c.pdf`
- **文件信息**：29.65 MB / 94 页
- **解析方法**：pdfplumber 提取表格，识别到 104 个表格块；其中第 43–92 页为「济宁市 2026 年度标志性产业链紧缺专业人才需求目录」7 列结构表
- **字段**：岗位名称 / 专业要求 / 紧缺星级 / 学历要求 / 任职能力要求 / 年薪均值（万元）/ 工作经验年数
- **识别到的产业链**（15→13 个）：工程机械、专用装备、汽车及零部件、新能源、煤化工、盐化工、食品、医药、新一代信息技术、造纸和纸制品、纺织服装、轻工、煤电
- **特殊处理**：
  - 表头与首条数据合并单元格（如「星级\n5星」）已按换行拆分
  - 同岗位多专业的续行已用上一行值向下填充（任职能力/年薪/经验/星级）
  - 岗位名脚注标记「☆N」已清除
- **样本**（首条，与任务示例完全一致）：
  ```json
  {"岗位名称":"工艺工程师","所属产业链":"工程机械","紧缺星级":"5星",
   "学历要求":"专科（高职）","专业要求":"机械设计制造及其自动化",
   "任职能力要求":"5年以上相关工作经验；熟悉机加工艺...","年薪均值（万元）":9.5,
   "工作经验年数":5,"数据来源":"蓝皮书2026版","数据采集日期":"2026-09-23"}
  ```

### 数据源 2a：济宁市属事业单位公开招聘（公告 B）

- **公告页**：`https://hrss.jining.gov.cn/art/2026/1/22/art_71291_2718366.html`
- **附件**：岗位汇总表 PDF（209.9 KB / 4 页），已下载并解析
- **字段**（15 列）：序号 / 事业单位 / 主管部门 / 岗位类别 / 岗位等级 / 岗位性质 / 岗位名称 / 招聘人数 / 学历要求 / 学位要求 / 大学本科专业要求 / 研究生专业要求 / 其它条件要求 / 咨询电话 / 备注
- **说明**：事业单位招聘无紧缺星级/年薪/经验字段，已统一映射为「—」或 null，「代表企业」填招聘单位名称
- **样本**：中共济宁市委党校-党校教师1（专业技术/初级/限 2026 届高校毕业生）

### 数据源 2b：校企双聘博士专引（公告 A）

- **状态**：❌ 济宁市人社局官网全站未检索到「2026 年校企双聘重点产业博士专引计划公告」
- **官网最新相关动态**：「济宁市打造博士生社会实践工作新范式」（2026-09-02），非岗位需求公告
- **建议**：该公告可能尚未发布或已归档，建议后续定期复查人社局「人事考试/招录招聘」栏目

### 数据源 3：汶上县招聘数据

- **站点访问**：`https://www.wenshang.gov.cn` 返回 403（反爬）；改用 `http://` 协议成功访问（HTTP 200）
- **春风行动汇总页**：❌ 站内未发现「2026 春风行动招聘会岗位汇总」专页；招聘栏目首页无此类汇总
- **退而采集**：栏目内 3 家企业招聘公告，共 10 条岗位记录
  1. 济宁市万有化工有限公司招聘信息（4 条：研发/生产技术/中控岗/操作岗）
  2. 汶上中银富登村镇银行招聘公告（5 条：客户经理等）
  3. 山东华准机械有限公司招聘简章（1 条）
- **字段**：企业名称 / 招聘岗位 / 招聘人数 / 岗位要求（已从中提取学历/专业/经验）

### 数据源 4：济宁直聘网

- **站点**：`https://www.jiningzhipin.com`（济宁网旗下，HTTP 200，服务端渲染，**无需登录**）
- **采集范围**：首页在招岗位 53 条（`.recruit-list__row` 结构）
- **字段**：岗位名称 / 公司名称 / 区域 / 薪资范围 / 详情链接 + 详情页补充（发布时间/学历/福利）
- **发布时间**：40/53 条已从详情页提取（均为 2026-09-23 在招）
- **年薪均值**：按「月薪范围 ×12 / 周薪 ×50」估算并换算为万元

## 五、异常与注意事项

1. **公告 A 未找到**：济宁市人社局官网未发布「2026 校企双聘博士专引计划公告」，无法采集。建议后续复查。
2. **汶上春风行动汇总页不存在**：官网无 2026 春风行动岗位汇总专页；已用栏内企业招聘公告替代，企业样本有限（3 家/10 条）。
3. **汶上县 HTTPS 被封**：站点对 HTTPS 返回 403，仅 HTTP 可访问；爬虫已固定使用 HTTP 协议。
4. **济宁直聘网首页多为推广位**：首页岗位多为「推广/楼层」付费推广位，发布时间需访问详情页补充；已补充 40 条。
5. **年薪估算口径不一**：蓝皮书为官方年薪均值；直聘网为「月薪×12」估算；事业单位无薪资数据。
6. **代表企业匹配基于关键字**：用企业名关键字推断产业链，可能存在误判；建议人工复核关键岗位。

## 六、复现方法

运行主控脚本即可复现全部采集流程：

```bash
cd "d:\新建文件夹 (2)\traesolo\job choose"
python scrapers/run_all.py
```

或按数据源分步执行：
```bash
python scrapers/fetch_bluebook_pdf.py        # 蓝皮书下载+解析
python scrapers/extract_directory.py        # 蓝皮书目录提取(730条)
python scrapers/fetch_hrss_pdf.py           # 人社局事业单位PDF
python scrapers/fetch_wenshang_notices.py   # 汶上县招聘公告
python scrapers/fetch_jiningzhipin.py       # 济宁直聘网首页
python scrapers/enrich_jzp_details.py      # 直聘网详情页补充
python scrapers/build_jobs_json.py          # 统一清洗→jobs.json
```

**依赖**：`pip install pdfplumber requests beautifulsoup4`（已在环境就绪）
**反爬策略**：请求间延迟 1.5–3 秒；政府站用 HTTP 协议；User-Agent 伪装为 Chrome。

**原始数据留存**（data/ 目录）：bluebook_2026.pdf、hrss_2026_institution_jobs.pdf、bluebook_directory_raw.json、hrss_institution_jobs_raw.json、wenshang_notices_raw.json、jiningzhipin_jobs_enriched.json 等，便于复核。
