# 济宁热门工作岗位分析与查询

济宁市重点产业链岗位需求的可视化分析与查询平台。纯前端项目，无后端依赖，全部数据以静态 JSON 内置在构建产物中。

**在线访问：** https://9yangtuo9.github.io/jining-jobs/

## 功能

| 页面 | 路由 | 说明 |
| --- | --- | --- |
| 首页概览 | `/` | 核心指标卡片、各产业链岗位数柱状图、学历分布饼图、热门岗位 TOP10，图表支持点击跳转 |
| 岗位查询 | `/jobs` | 关键词搜索（300ms 防抖）、产业链/学历/紧缺星级多选筛选、薪资区间双滑块、排序、分页（20 条/页） |
| 岗位详情 | `/jobs/:id` | 岗位完整信息、一键复制公司名称、"如何应聘"指引（BOSS 直聘 / 企查查 / 百度） |
| 数据分析 | `/dashboard` | 各产业链平均年薪对比、技术岗/市场岗/职能岗占比、薪资区间分布直方图（8 档），以及有年薪数据岗位数、平均年薪最高产业链、技术岗占比、主流薪资区间等指标 |

所有筛选条件都写入 URL 查询参数，可复制链接分享特定筛选结果。

## 本地运行

需要 Node.js 18 或更高版本。

```bash
npm install
npm run dev
```

打开 http://localhost:5173/

## 可用命令

| 命令 | 说明 |
| --- | --- |
| `npm run dev` | 启动开发服务器 |
| `npm run build` | 生产构建，输出到 `dist/` |
| `npm run build:ghpages` | GitHub Pages 专用构建（资源路径加 `/jining-jobs/` 前缀） |
| `npm run preview` | 本地预览构建产物 |
| `npm run update-data` | 重新清洗数据并生成 `src/data/` 下的 JSON |

## 数据更新流程

```
raw_jobs.json  ──[ npm run update-data ]──▶  src/data/jobs_clean.json
（原始采集数据）                              src/data/jobs_stats.json
```

1. 将新的原始采集数据（格式同 `data/jobs.json`，含 `records` 与 `data_acquisition_date` 字段）放到项目根目录，命名为 `raw_jobs.json`
2. 执行 `npm run update-data`
3. 脚本会完成：岗位名称清洗、产业链标准化归类、学历/专业标准化、薪资解析与年薪估算、按「岗位名称 + 产业链」去重聚合、统计汇总
4. 提交并推送到 `main`，网站自动更新

> 脚本对输入有校验：若 `raw_jobs.json` 中带有 `raw_total` 字段（说明误放了已清洗数据），会输出警告提示。

## 部署

推送到 `main` 分支后，[deploy-pages.yml](.github/workflows/deploy-pages.yml) 会自动完成构建与发布，约 1 分钟后生效。

由于站点部署在子路径下，构建使用了 `--mode ghpages` 让 Vite 的 `base` 变为 `/jining-jobs/`，同时路由的 `basename` 取自 `import.meta.env.BASE_URL`，因此 `/` 根路径部署（如本地或 Vercel）也依然可用。

子页面直接刷新依赖 GitHub Pages 的 404 兜底：构建时会把 `index.html` 复制为 `404.html`，由前端路由接管渲染。
